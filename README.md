# Hospital Management System 🏥

A robust terminal-based full-stack CRUD application built using **Python** and **MySQL**. This application manages patient administration workflows by performing core relational database operations securely.

## 🚀 Features
- **Add Patients:** Inserts fresh records directly into the MySQL database.
- **Display Records:** Fetches and streams all patient profiles clearly onto the screen.
- **Search System:** Instantly finds specific records using targeted database queries.
- **Update Records:** Edits patient data safely using parameters.
- **Delete Functionality:** Permanently removes records directly by unique IDs.

## 🛠️ Tech Stack
- **Backend:** Python 3
- **Database:** MySQL
- **Driver:** `mysql-connector-python`

## ⚙️ How to Setup
1. Clone this repository to your system.
2. Ensure you have MySQL server running on your computer.
3. Configure a database named `hospital` and update your username/password strings inside the code script.
4. Run the application:
   ```bash
   python mysql_connector_proj.py
   ```
